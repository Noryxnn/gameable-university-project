# Newsletter Email Template Documentation

## Overview
The newsletter email template is a clean, professional HTML email designed to be compatible with major email clients (Gmail, Outlook, mobile devices) while maintaining a modern, branded appearance.

## Template Features

### ✅ Requirements Met
- **Inputs**: `userName`, `gameTitle`, `gameLink`
- **Email Client Compatibility**: Gmail, Outlook, mobile devices
- **Friendly Greeting**: Uses user's name: "Hi {userName},"
- **Highlighted Game Title**: Game title is prominently displayed in a styled box
- **CTA Button**: "Check It Out" button with gradient styling
- **Footer**: Brand name (GameAble Team) + unsubscribe message
- **Inline CSS**: All styles are inline for maximum email client compatibility

### Design Elements

1. **Header**
   - Gradient background (purple to pink)
   - Brand name: "🎮 GameAble"
   - Centered, bold typography

2. **Main Content**
   - Personalized greeting using user's name
   - Clear message about new game addition
   - Game title highlighted in a styled box with left border accent
   - Call-to-action button with gradient background
   - Thank you message

3. **Footer**
   - Light gray background
   - Brand signature: "— GameAble Team"
   - Unsubscribe link pointing to profile page
   - Professional, unobtrusive styling

### Technical Implementation

#### Template Generation
The template is generated by the `generateNewsletterTemplate()` method in `NewsletterService`:

```javascript
generateNewsletterTemplate(userName, gameTitle, gameLink)
```

#### Email Structure
- **Subject**: "New game added: {gameTitle}"
- **HTML**: Full HTML template with inline CSS
- **Plain Text**: Fallback text version for email clients that don't support HTML

#### Responsive Design
- Uses table-based layout (most compatible with email clients)
- Max-width: 600px (optimal for email viewing)
- Mobile-friendly viewport meta tag
- Padding and spacing optimized for small screens

### Email Client Compatibility

#### ✅ Tested/Designed For:
- **Gmail** (Web, iOS, Android)
- **Outlook** (Desktop, Web, Mobile)
- **Apple Mail** (iOS, macOS)
- **Mobile clients** (iOS Mail, Gmail Mobile, Outlook Mobile)

#### Compatibility Features:
- Table-based layout (works in all email clients)
- Inline CSS (no external stylesheets)
- Web-safe fonts (Arial, Helvetica, sans-serif)
- No JavaScript (email clients strip JS)
- Proper DOCTYPE and meta tags

### Color Scheme

- **Primary Gradient**: `#9333ea` (purple) to `#ec4899` (pink)
- **Text Primary**: `#333333` (dark gray)
- **Text Secondary**: `#666666` (medium gray)
- **Background**: `#ffffff` (white)
- **Accent Border**: `#9333ea` (purple)
- **Footer Background**: `#f9fafb` (light gray)

### Link Generation

The game link is automatically generated from:
- `FRONTEND_URL` environment variable (or defaults to `http://localhost:5173`)
- Game ID: `game._id`
- Final URL: `${FRONTEND_URL}/game/${game._id}`

Example: `https://gameable.com/game/507f1f77bcf86cd799439011`

### Unsubscribe Link

The unsubscribe link points to the user's profile page:
- URL: `${FRONTEND_URL}/profile`
- Users can toggle newsletter preferences from their profile

## Usage Example

```javascript
// In NewsletterService.sendNewGameAnnouncement()
const html = this.generateNewsletterTemplate(
  user.username || 'there',
  game.title,
  gameLink
);

await emailService.send({
  to: user.email,
  subject: `New game added: ${game.title}`,
  body: plainTextVersion,
  html: html
});
```

## Customization

To customize the template:

1. **Colors**: Modify the gradient colors in the header and button
2. **Branding**: Change "GameAble" to your brand name
3. **Styling**: Adjust inline CSS styles in the template
4. **Content**: Modify the greeting, message, or footer text

All changes should maintain inline CSS for email client compatibility.
